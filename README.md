# ついびゅ

**ついびゅ**は、CSV・XML・JSON形式で保存したX（旧Twitter）の投稿データを、Xに近いタイムライン形式で閲覧・検索・整理できるビューアです。

投稿データは外部サーバーへ送信せず、利用しているブラウザ内で扱えます。保存した投稿を後から読み返したり、アカウントやキーワードごとに整理したりする用途に向いています。

## 主な機能

- CSV・XML・JSON形式の投稿データを読み込み
- アカウント・キーワード・ハッシュタグごとのコレクション管理
- X風のタイムライン表示
- 投稿詳細、返信、引用投稿、画像・動画の表示
- キーワード検索と高度な検索
- いいね数、リポスト数、返信数、日付による絞り込み
- 投稿のブックマーク保存と一覧表示
- 投稿データのCSV書き出し
- CSVデータの画面上での編集
- プロフィール名、メモ、アイコン、バナーの編集
- ライト・ダーク・システム連動テーマ
- 日本語・英語表示
- スマートフォン・PC対応
- PWA対応（ホーム画面への追加）

## 対応しているデータ

- Xporterなどのツールから書き出したCSV・JSON
- X API由来のJSON
- XML形式の投稿データ
- 手動で作成したCSV

読み込んだデータは、コレクションとしてブラウザに保存されます。大切なデータは、元ファイルを別途バックアップしてください。

## 技術
- React
- TypeScript
- Vite
- Papa Parse（CSV解析）
- Lucide・Tabler Icons
- CSS
- Web Storage API（ブラウザ内保存）
- Web Manifest・Service Worker（PWA）

## プライバシー

通常の利用では、読み込んだ投稿データをついびゅのサーバーへアップロードしません。データやブックマーク、表示設定は利用中のブラウザに保存されます。

共有端末で利用した場合は、利用後にアプリ内のデータ削除やブラウザのサイトデータ削除を行ってください。

## 注意事項

ついびゅは、X Corp.、Twitter、Xporterなどの各種エクスポートツールとは関係のない非公式ビューアです。Xの仕様変更やデータ形式によっては、正しく読み込めない場合があります。
