# TwView (ついびゅ)

TwView は、CSV / XML / JSON でほぞんした X / Twitter のとうこうデータを、ブラウザで X ふうにみられるローカルビューアです。

データはブラウザの LocalStorage にほぞんされます。サーバーへとうこうデータをおくらず、このたんまつだけであつかえます。

## サービスしょうかい

TwView は、エクスポートしたとうこうアーカイブを、あとからよみかえすためのツールです。タイムライン、とうこうしょうさい、メディア、ブックマークをまとめてみられます。

## きのうしょうかい

- CSV / XML / JSON のインポート
- アカウント、キーワード、ハッシュタグごとのコレクション
- X ふうタイムライン
- とうこうしょうさいのひょうじ
- へんしん、いんよう、URL、メディアのひょうじ
- ブックマーク
- キーワードけんさく
- いいねすう、リポストすう、へんしんすう、ひづけでのこうどなけんさく
- CSV エクスポート
- CSV のぜんがめんテーブルへんしゅう
- プロフィール、アイコン、バナーのへんしゅう
- ライト / ダーク / システムテーマ
- にほんご / えいご UI
- PWA たいおう

## ローカルきどう

```bash
npm install
npm run dev
```

かいはつサーバーはいかできどうします。

```text
http://localhost:4100
```

## ビルド

```bash
npm run build
```

ビルドしたファイルは `dist/` にできます。

## たいおうデータ

- Xporter けいツールの CSV / JSON
- てづくりの CSV
- X API の JSON
- XML のとうこうデータ

CSV はアプリのなかでへんしゅうできます。ほぞんすると、へんしゅうした内容でコレクションをよみこみます。

## ちゅうい

TwView は X Corp.、Twitter、エクスポートツールとはかんけいのない非公式ビューアです。

とりこんだデータ、ブックマーク、せっていはブラウザにほぞんされます。きょうゆうたんまつでは、りようごにデータをけしてください。
