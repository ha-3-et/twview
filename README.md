# ついびゅ

ついびゅ は、CSV / XML / JSON 形式で保存した X（旧Twitter）の投稿データを、ブラウザ上で X 風のタイムラインとして閲覧できるローカルビューアです。

インポートしたデータ、ブックマーク、表示設定はブラウザの LocalStorage に保存されます。外部サーバーへ投稿データを送信せず、端末内で閲覧・整理できます。

## サービス紹介

ついびゅ は、自分で保存した投稿アーカイブや検索結果のエクスポートデータを、後から読み返しやすくするためのビューアです。

投稿、返信、引用、メディア、プロフィール情報、投稿詳細、ブックマークを X に近い表示で扱えます。

## 機能紹介

- CSV / XML / JSON の投稿データをインポート
- アカウント、キーワード、ハッシュタグ別のコレクション管理
- X 風のタイムライン表示と投稿詳細表示
- 返信、引用投稿、URL、画像・動画メディアの表示
- ブックマーク保存とブックマーク一覧
- キーワード検索と高度な検索（いいね数、リポスト数、返信数、日付）
- CSV エクスポート
- CSV データの全画面テーブル編集
- プロフィール名、メモ、アイコン、バナーの編集
- ライト / ダーク / システム連動テーマ
- 日本語 / 英語表示
- PWA 対応

## Google Analytics 4

Google Analytics 4 は、測定IDを設定したビルドでのみ有効になります。GitHub Pagesで有効化する場合は、GitHubリポジトリの **Settings → Secrets and variables → Actions → Variables** に次のリポジトリ変数を追加してください。

- 名前: `VITE_GA_MEASUREMENT_ID`
- 値: `G-XXXXXXXXXX` 形式のGA4測定ID

変数を追加して `main` にプッシュすると、GitHub Actionsが再ビルドしてGA4のトラッキングコードをページの`head`へ追加します。測定ID未設定時はGA4のスクリプトを読み込みません。Google Analyticsを利用する場合は、プライバシーポリシーにも利用目的とオプトアウト方法を記載してください。

## 対応データ

- Xporter 系ツールで出力した CSV / JSON
- 手動で作成した CSV
- X API 由来の JSON
- XML 形式の投稿データ

CSV データはアプリ内で編集できます。保存すると、編集後の内容でコレクションが再読み込みされます。

## 注意事項

ついびゅ は X Corp.、Twitter、各種エクスポートツールとは関係のない非公式ビューアです。

共有端末で利用する場合は、利用後にアプリ内のデータ削除やブラウザのサイトデータ削除を行ってください。
